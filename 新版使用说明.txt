三国杀 OL 奖励领取快速版 / 2026-11-27

使用
1. 保持 Chrome 使用平时登录 4399 的用户资料。游戏标签页可以关闭。
2. 官网和游戏页的浏览器缩放会自动恢复到校准使用的 100%。窗口尺寸和主屏幕布局仍需保持校准时的样式。
3. 双击“启动.command”，直接回车选择“一键巡检”。
4. 可以切换到其他应用或浏览器标签：脚本会暂停，切回游戏页面后自动继续，无须重新启动；等待时间不计入领取和页面识别超时。暂停期间不会点击其他应用。
5. 这仍是前台鼠标自动化，不能在你操作其他应用时同时后台领取。领取期间不要操作游戏或改变窗口位置。Ctrl+C 可中止；鼠标移至主屏左上角可触发停止。

浏览器缩放处理
每次窗口截图和鼠标操作前，检查 Chrome 地址栏的缩放百分比；结果最多缓存 0.25 秒，窗口或前台切换后立即重查。发现偏离 100% 时自动重置，确认恢复后再继续。
官网和游戏标签分别检查。只读扫描不修改缩放。切换应用期间继续暂停，不会给其他应用发送缩放操作。
本版采用恢复校准比例的方式，尚未实现保持任意缩放比例继续领取，也不代表已经适配其他分辨率或任意窗口大小。
窗口移动、大小改变仍会停止，防止已识别画面和点击坐标不一致。
页面标题和领取按钮支持约 90%–110% 的小幅尺寸匹配，并在原区域周围搜索位置偏差；不代表任意分辨率适配。左侧入口按文字定位，返回大厅时按当前叉号位置关闭，避免菜单增减和窗口内部布局小幅变化导致卡住。

自动登录
修正：官网入口优先按 Chrome 辅助功能中的精确链接名“三国杀OL”点击；截图模板仅作为后备，减少按钮样式、缩放或滚动影响。
终端启动时会主动启用 Chrome 网页辅助功能树，并等待官网加载完成后点击；点击后单独等待游戏标签就绪，避免用官网标题校验新游戏页而误暂停。每次最多等待八秒，最多尝试三次。
现在默认先登录，再领取：已有游戏标签页时直接切过去；没有时打开或切换官网，点击右侧的“三国杀 OL 开始游戏”。
复用 Chrome 已保留的 4399 登录状态，等待游戏进入大厅，关闭已识别的启动宣传弹窗后继续领取。
已在当前账号验证官网自动进入游戏，无须脚本保存账号密码。
若 4399 登录状态过期，账号登录或验证码仍需在浏览器完成；OL 开始游戏由脚本点击。若验证期间脚本已停止，完成验证后重新运行即可。
本版未实现无登录状态时自动填写账号密码，不绕过验证码；未适配的选服、维护或提示页面会超时停止。
如 macOS 提示控制 Google Chrome，请允许终端控制 Chrome。仍需原有的辅助功能、屏幕录制权限。
双击脚本由“终端”运行：若提示缺少权限，需要给“终端”授权，仅给 Codex 授权不能代替终端权限。脚本会明确报告缺少的权限。

费用范围
按最新授权，发财树每天允许最多消耗150元宝。除此之外不购买、不补签、不兑换，不使用元宝、银两或背包中已有的抽取券和道具。
公会只执行明确显示“不消耗道具”的剩余免费次数；抽将只执行“免费开启”单抽；祈福只执行明确的免费祈福。
发财树核对150元宝价格后最多请求一次，拾取落地元宝、处理奖励弹窗，确认今日已完成后退出。结果不明时本日不重复消费；本地记录在.tree-spend.json，不上传仓库。--tree-budget 0 可禁用付费砍树。

速度与实测

只巡检的一次实测主体约 8.47 秒，从 Python 启动到退出约 10.07 秒。

此前加入小幅尺寸匹配、动态侧栏定位及点击前宣传页检查后，一次完整巡检实测约22.55秒。新增活动页和继续提示检查后，耗时会有所增加。
全部奖励待领取时还会增加弹窗、网络及抽将动画时间，不能保证所有奖励几秒内完成。

文件
sgs_fast.py：快速版主程序。
sgs_login.py：Chrome 标签切换、官网进入和登录就绪检查。
sgs_zoom.py：Chrome 缩放百分比检查与恢复。
sgs_tree.py：发财树每日150元宝上限与防重复消费。
templates_v2.json 与 templates_v2/：本次游戏界面的识别模板。
fast_runs/：一次启动共用一个目录，登录和巡检合写 log.json（phase 字段区分阶段），结束截图为 last.jpg。
默认自动保留最近 20 次；--keep-runs N 可调整。仍在运行的目录不会被清理。总时长包含登录和暂停时间，操作超时不计暂停时间。
加 --debug 会额外保存过程截图，便于定位漏领。
sgs_daily.py、启动_旧版.command、使用说明.txt：保留的第一版。

终端运行（先进入本文件所在目录）
.venv/bin/python sgs_fast.py --module all --execute
只读检查：.venv/bin/python sgs_fast.py --module scan
调试记录：.venv/bin/python sgs_fast.py --module all --execute --debug
仅登录：.venv/bin/python sgs_fast.py --module login --execute
