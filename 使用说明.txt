三国杀 OL 免费领取原型（旧版） / 2026-11-26

当前快速版请阅读“新版使用说明.txt”；默认“启动.command”已切换到快速版。
本文件以下内容描述第一版，旧菜单保存在“启动_旧版.command”。

这是已经在当前账号实际试跑的 Mac 本地脚本，使用 Chrome、PyAutoGUI、Apple Vision 中文 OCR 和截图模板。
本地运行，不使用 AI API，不保存账号密码，不读取游戏登录 token。

目前是“手动打开页面 → 运行对应模块”的版本。
尚未实现自动登录、自动巡视所有红点、遍历全部活动、定时上线、自动关闭所有奖励弹窗。
不要把本版当作无人值守的每日全自动成品。

使用
1. 在 Chrome 登录三国杀 OL。游戏窗口完整放在主显示器内。
2. 将浏览器和游戏显示尺寸保持为本次校准的样式；移动窗口可以，改变浏览器缩放后应重新校准模板。
3. 手动打开下面列出的对应页面。
4. 双击同目录的“启动.command”，输入模块编号。脚本会将 Chrome 切到前台。
5. 运行时不要操作鼠标。鼠标移到主屏左上角，或终端 Ctrl+C，可中止。
6. 查看 runs/日期时间/ 内的 log.json、原始截图、OCR JSON 和标注图。
   绿色框是 OCR 文字；青色框是红点候选，并不是已确认可免费领取的全部项目。

已接入的页面
签到/福利：福利 → 每日签到，只点今日“签到”，看到“补签”就跳过。
任务：任务 → 左侧“任务”标签，只领取当前可见列表中的绿色领取按钮，不执行对局任务，不滚动遍历全部任务。
官阶：官阶 → 每日俸禄，有对应红点才领取，不点提升帅点。
公会擂鼓：公会 → 公会擂鼓，只点最左侧常山战鼓；先悬停确认“不消耗道具”和剩余次数大于零。
武将抽取：武将 → 招武将 → 常驻招募；也可从大厅“招募”入口进入。
          只在左侧显示“免费开启”且有对应红点时点一次。不会花招募令，不点五连抽。
祈福：当前“小雪祈福”的“免费祈福”。不消耗灯笼或元宝。活动换版可能需要重新校准。
活动：仅已适配“活动 → 充消返利 → 充值福利 → 免费好礼”，不是全部活动。
发财树/摇钱树：当前页面显示需要150元宝，保持禁用。即使入口有红点也不会点击。

命令行
先 cd 到本文件夹，再执行：
.venv/bin/python sgs_daily.py list
.venv/bin/python sgs_daily.py scan
.venv/bin/python sgs_daily.py run --module 签到
.venv/bin/python sgs_daily.py run --module 签到 --execute --focus
.venv/bin/python verify_replay.py

不加 --execute 时不会点击；公会的免费提示检查需要悬停，所以观察模式只提示检查计划。
scan 只截取游戏窗口；run --execute 要求游戏实际位于前台。
遇到验证码、登录失效或不认识的页面会停止，不会自动确认未知弹窗。

结果判定
签到：今日按钮变为“补签”的已校准样式。
任务：当前页领取按钮数量减少。
官阶/活动/抽将/祈福：对应页面内奖励红点消失，或识别到已领取/奖励结果。
公会：重新悬停刷新提示后，免费次数减少；“今日的击鼓次数已用完”视为0。
动画或 OCR 没有及时给出可识别证据时，会记为“结果未验证”并停止。先看截图，不要直接反复重试。
祈福的首次试跑遇到了较长动画，奖励已由后续画面确认；已延长结果观察，但新的等待设置尚未用下一次免费机会实测。
verify_replay.py 使用本次保留的真实截图执行9项只读回放检查，不会移动鼠标。

本次实际试跑

日常任务：领取登录游戏、在线10分钟两项，当前页领取按钮 2 → 1 → 0。
官阶：每日俸禄，银两×100；变为“明日可领奖”。

武将：免费单抽 SP 孙尚香，重复武将由游戏转换为3个对应材料。
小雪祈福：4次 → 5次，夺宝券×1。
活动免费好礼：已执行领取，对应红点消失。
试跑没有执行任何消耗元宝、银两或已有道具的操作。
部分最初试跑曾因 OCR/动画未识别到结果而记为“未验证”；上面的结果由后续画面核对，原始日志保留。

环境
当前 .venv 已装好运行依赖，并复用了本机已有的 NumPy/OpenCV。
如果迁移到另一台 Mac，用 Python 3.12 创建虚拟环境，再安装 requirements.txt。
首次从终端运行时，如 macOS 提示，需要为实际运行的终端应用开启屏幕录制和辅助功能权限。

扩展
识别规则在 recipes.json，按钮截图在 templates/，主程序在 sgs_daily.py。
新增活动应先确认具体页面、免费条件、目标按钮和领取结果，再增加规则。
本版没有注册定时任务。后续做自动每日巡检，需要先完成大厅导航、子页切换、弹窗关闭和登录失效处理。
